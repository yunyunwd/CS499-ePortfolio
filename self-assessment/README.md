# Professional Self-Assessment

Completing the Computer Science program at Southern New Hampshire University has helped me develop both technical skills and a better understanding of how different areas of computer science work together. When I started the program, I was mainly interested in learning programming and data-related skills. As I completed more courses, I learned that computer science is not only about writing code. It also requires problem solving, communication, collaboration, security awareness, and the ability to design solutions that meet the needs of users and organizations. Developing this ePortfolio has allowed me to review my progress and see how much my technical and professional skills have grown.

One of the most important areas I developed throughout the program was **collaboration and communication**. Software projects are rarely completed by one person without input from others. Even when working on individual assignments, I learned to think about how another developer, user, or stakeholder would understand my work. Clear documentation, comments, organized code, and understandable interfaces make it easier for others to use and maintain a system. I also learned that technical communication needs to be adjusted for different audiences. A developer may need detailed technical information, while a manager or user may be more interested in what a system does, why a change is needed, and how it improves the final product. My CS 499 code review helped me practice this skill because I needed to explain the existing application, identify problems, and describe planned improvements without making the presentation unnecessarily technical.

My coursework also strengthened my understanding of **data structures and algorithms**. Earlier in the program, I learned that a working solution is not always the best solution. The organization of data and the choice of an algorithm can affect performance, usability, and scalability. Through programming assignments, I gained experience thinking about searching, sorting, organizing information, and choosing appropriate approaches for solving problems. This knowledge became especially useful during my capstone when I enhanced the Travlr Getaways application with search, filtering, and sorting capabilities. However, the skills behind that enhancement were developed across several courses and programming experiences throughout the program. I now approach programming problems by considering not only whether the code works, but also whether the solution is logical, efficient, and maintainable.

Another major area of growth has been **software engineering and database development**. Throughout the program, I worked with several programming languages and technologies, including Java, C++, Python, SQL, JavaScript, and full-stack web development tools. These experiences helped me understand that software development involves more than creating individual functions. A complete application includes user interfaces, application logic, data management, error handling, and communication between different components. My database coursework also gave me experience with relational databases and SQL, while later projects introduced me to technologies such as MongoDB and REST APIs. This combination helped me understand both structured relational data and more flexible non-relational approaches.

The program also increased my awareness of **security**. Security cannot be added only after an application is completed. Developers need to consider security throughout the design and development process. Coursework involving secure coding and software design helped me think about issues such as authentication, input validation, data protection, access control, and potential vulnerabilities. Even when security is not the main purpose of a project, developers need to consider how data and system resources could be misused or exposed. This security mindset has changed the way I evaluate software because I now consider both functionality and possible risks when designing or reviewing an application.

My experience in the program has also helped shape my professional goals. I have developed strong interest in areas where technology, data, and real-world operations connect. I enjoy solving practical problems and improving processes rather than working only with abstract technical concepts. My experience with programming, databases, data analysis, and system design gives me a broad technical foundation that can support different career paths. The program has also shown me that my ability to analyze problems, communicate clearly, and understand both technical and operational needs can be valuable in technology-related roles.

The artifacts in this ePortfolio demonstrate this development through one application, **Travlr Getaways**, enhanced in three different areas. The Software Design and Engineering enhancement focuses on usability, structure, error handling, and application behavior. The Algorithms and Data Structures enhancement adds more effective methods for searching, filtering, and sorting trip information. The Database enhancement expands the system by adding booking functionality and connecting new database components with the administrative interface. Together, these enhancements show how software engineering, algorithms, and databases are interconnected rather than separate areas of computer science.

Overall, completing the Computer Science program and developing this ePortfolio have helped me recognize both my technical growth and my professional strengths. I have learned how to design and improve software, work with data, apply algorithmic thinking, consider security, and communicate technical ideas more effectively. More importantly, I have developed the ability to look at a problem from multiple perspectives and select technologies and approaches that support the needs of the user and the organization. This ePortfolio represents not only the technical work I completed during the program, but also the way my approach to problem solving and software development has developed throughout my studies.
