# Database Enhancement

## Artifact

Travlr Getaways Web Application (CS 465)

## Overview

This enhancement focuses on expanding the database functionality of the Travlr Getaways application.

For this enhancement, I added a Booking collection, including the model, controller, routes, and REST API functionality. I also added Booking components to the Angular administrative interface so booking information can be viewed and managed through the application.

These changes demonstrate my ability to integrate database functionality into a full-stack application.

The narrative for this enhancement describes the original artifact, the database changes I made, and how the enhancement demonstrates my database development skills.
