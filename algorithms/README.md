# Algorithms and Data Structures Enhancement

## Artifact
Travlr Getaways Web Application (CS 465)

## Overview
This enhancement focuses on improving the search, filtering, and sorting functions in the Travlr Getaways application. The original application displayed trip information, but it had limited options for finding and organizing trips.

For this enhancement, I added multiple search and filtering options, including destination, price, duration, and season. I also added sorting functions that allow trip information to be organized by price or duration.

These changes improve the usability of the application and demonstrate my ability to apply algorithms and data structures to an existing software project.

## Enhancement Narrative
The narrative for this enhancement describes the original artifact, the changes I made, and how the enhancement demonstrates my skills in algorithms and data structures.
